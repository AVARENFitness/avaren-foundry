# Design System

## Design direction

AVAREN should feel like a refined training space: dark materials, restrained gold, strong typography, precise spacing, and purposeful motion.

## Brand voice

Use language that is:

- Calm
- Strong
- Direct
- Intelligent
- Encouraging
- Never overly corporate
- Never childish
- Never aggressively motivational

Examples:

- “Forged.”
- “Built over time.”
- “Recovery is keeping pace.”
- “Return to the set that matters.”
- “Look how far you’ve come.”

## Visual roles

### Background

Near-black surfaces with subtle depth.

### Primary accent

Foundry gold for action, achievement, progress, and emphasis.

### Recovery accent

Muted green for recovery, readiness, and completion.

### Warning accent

Warm rust for low readiness, destructive actions, and attention.

### Cream text

Primary readable text should be warm rather than pure white.

## Component families

### Hero Card

Used for the primary action or daily focus.

### Insight Card

Used for Recovery Intelligence and future Coach insights.

### Timeline Card

Used in The Journey for workouts, PRs, recovery, and milestones.

### Stat Card

Used for compact metrics and analytics.

### Achievement Card

Used for milestone and Forge progress.

### Flow Card

Used for Daily Reset and Recovery Flow entry points.

### Section Header

Uses eyebrow, title, and optional supporting sentence.

## Interaction rules

- Primary actions should remain obvious on mobile.
- Fixed elements cannot obscure navigation or workout controls.
- Modals must attach to the viewport using a portal when app containers are transformed.
- Timers never start automatically.
- Timers never force automatic movement advancement.
- Destructive actions require confirmation.
- Important state changes should save immediately.
- Haptics should be subtle and optional.

## Motion

Motion should communicate state rather than decorate the interface.

Use motion for:

- Screen transitions
- Celebration reveals
- Progress changes
- Modal entrance
- Timer state
- Completion acknowledgment

Respect reduced-motion preferences in a future accessibility pass.

## Accessibility priorities

- Sufficient contrast
- Large mobile tap targets
- Semantic buttons
- Clear focus states
- Screen-reader labels
- Reduced motion
- No color-only status communication
