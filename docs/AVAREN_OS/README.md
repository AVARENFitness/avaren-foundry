# AVAREN OS

AVAREN OS is the internal blueprint for AVAREN: The Foundry.

It defines what AVAREN is, how its systems fit together, how releases are planned, and how the project is developed safely as it grows.

## Core product idea

AVAREN is not only a workout logger. It is a training companion that helps an athlete:

1. Prepare to move.
2. Train with focus.
3. Recover intentionally.
4. Understand progress.
5. Build a lasting story through The Journey.

## Product rule

Every major feature should answer at least one of these questions:

- Does this help the athlete train better today?
- Does this improve recovery or readiness?
- Does this make progress easier to understand?
- Does this give the athlete a reason to return tomorrow?
- Does this strengthen the relationship between coach and client?
