# AVAREN OS 2.0.1

## Illustrated Character Renderer

### Changed

- Replaced floating capsule body parts with a connected illustrated body
- Added connected shoulders, torso, waist, pelvis, arms, and legs
- Added visible elbows, knees, hands, and feet
- Preserved Motion Studio frame sequences, scrubber, speed controls, side switching, and expanded view
- Improved muscle-highlight placement so it follows each active pose

### Goal

Keep the successful Motion Studio interaction while making every pose read immediately as a human movement.
