# AVAREN OS 2.0

## Motion Studio Foundation

### Added

- Rigged vector character with filled body parts
- Movement-specific frame sequences
- Multi-phase Neck CARs
- Three-stage mobility movements
- Frame-by-frame scrubbing
- Playback-speed controls
- Expandable movement viewer
- Side switching
- Target-area highlighting
- Floor and wall landmarks
- Scalable pose-data architecture

### Design change

Motion Studio no longer relies on one generic start/finish pair. Each supported movement defines its own sequence of key frames.
