# AVAREN Builder v1.1

## Release

Sprint 8C — Daily Readiness Intelligence

## Added

- Daily sleep, energy, soreness, and stress check-in
- Editable same-day readiness entry
- Readiness score
- Readiness status and recommendation
- Saved readiness history
- Home readiness card
- Home readiness badge integration
- Coach readiness insights
- Readiness-aware Daily Reset guidance
- Training-load and mobility adjustments

## Data model

Daily readiness entries are stored in `state.readiness.entries` and sync through the existing local-first cloud state.
