# AVAREN Builder v1.4

## Release

Workout Session Controls

## Added

- Functional Gym Mode workout-options menu
- Change Workout action
- Restart Workout action
- End Without Saving action
- Confirmation before discarding entered progress
- Safe removal of empty or abandoned active workouts
- Automatic return Home after ending a session

## Data behavior

Ending without saving does not create a completed workout and does not affect:

- Workout History
- The Journey
- The Forge
- Milestones
- Training streaks
- Weekly completion
- Training volume
- Personal records
