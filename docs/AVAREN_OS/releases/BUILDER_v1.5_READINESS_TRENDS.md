# AVAREN Builder v1.5

## Release

Readiness Trends

## Added

- Dedicated Readiness Trends screen
- 7-day and 30-day readiness averages
- Best and lowest readiness days
- Readiness consistency score
- Sleep, energy, soreness, and stress trends
- Workout-day and rest-day readiness averages
- PR-day readiness comparison
- Low-readiness workout count
- Progress-screen readiness entry point
- Home readiness-card trend navigation
- Low-readiness recovery guidance

## Data behavior

The feature reads existing readiness entries and workout history. No migration is required.
