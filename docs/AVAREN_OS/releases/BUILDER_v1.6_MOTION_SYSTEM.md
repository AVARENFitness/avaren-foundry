# AVAREN Builder v1.6

## Release

Motion System Foundation

## Added

- Reusable animated SVG movement-illustration component
- Visual movement patterns inside Mobility flows
- Direction arrows
- Target-area labels
- Motion cues
- Play, pause, and replay controls
- Reduced-motion accessibility fallback
- Visual metadata for the complete current mobility library
- Support for standing, quadruped, child-pose, and prone movement families

## Fixed

- Notification Center Back now returns Home instead of More.

## Notes

These are lightweight vector illustrations rather than videos. They show movement direction and body position while preserving fast loading and offline use.
