# AVAREN Builder v1.8

## Release

Motion System 2.0

## Added

- New pose-to-pose vector rendering system
- More natural body proportions and rounded joints
- Dedicated poses for priority mobility movements
- Smooth interpolation between start and finish positions
- Left/right side switching
- Start and finish labels
- Target-muscle highlighting
- Motion trails
- Breathing, tempo, range, and common-mistake guidance
- Static three-step mode while paused
- Better mobile layout
- Reduced-motion support
