# AVAREN Builder v1.9

## Release

Motion System 3.0 — Clarity Upgrade

## Added

- Filled athletic silhouettes
- Visible torso, limbs, hands, and feet
- Side-by-side start and finish poses
- Manual start and finish pose selection
- Larger optional animated guide
- Floor and wall landmarks
- Stronger target-area shading
- Clearer movement arrows
- Numbered setup, movement, and breathing instructions
- Better phone layout
- Reduced-motion compatibility

## Design principle

Animation now supports the instructions rather than replacing them. Users can understand the movement from the static start and finish poses alone.
