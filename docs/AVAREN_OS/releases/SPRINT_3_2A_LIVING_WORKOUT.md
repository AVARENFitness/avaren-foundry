# Sprint 3.2A — The Living Workout

## Added

- Live elapsed workout clock
- Live completed volume
- Completed-set and exercise counters
- Dynamic session intensity label
- Comparison with the last workout of the same name
- Current exercise session snapshot
- Set-completion pulse and haptic feedback
- Smoother exercise spotlight transitions
- Expanded completion metrics
- Session density in pounds per minute
- Exercise and PR counts in the final summary

## Product direction

AVAREN observes and summarizes the workout the user chose. It does not prescribe or replace the user's program.
