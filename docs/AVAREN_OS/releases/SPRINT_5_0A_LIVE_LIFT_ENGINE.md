# Sprint 5.0A — Live Lift Engine

## Goal
Improve the active lifting experience without changing workout data.

## Added
- Live workout duration clock
- Automatic rest timer after completing a set
- Pause, resume, add 30 seconds, restart, and dismiss controls
- Configurable default rest duration
- Potential weight and estimated-strength PR indicators
- Rest-complete vibration feedback
- Corrected and replaced the current FocusExercise implementation

## Preserved
- Existing workout state
- Supersets
- Previous-session data
- Cloud sync
- Completion summary
- Set types, quick add, skip, repeat, and remove
