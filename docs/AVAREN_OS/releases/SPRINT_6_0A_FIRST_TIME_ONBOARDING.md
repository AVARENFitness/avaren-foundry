# Sprint 6.0A — First-Time Onboarding & App Tour

## Added
- Five-step first-time walkthrough
- Home, readiness, Gym, recovery, completion, and progress guidance
- Tour appears only after account state finishes loading
- Tour completion is stored in local and cloud-synced user state
- Existing users with prior activity are automatically marked as onboarded
- Replay App Tour action under Profile
- Replay does not reset data or first-time completion status
- Skip Tour option for new users
