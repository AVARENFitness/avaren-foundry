# Sprint 6.0B — Coach-First Hub Foundation

## Added
- Dedicated Coach Mode with its own shell and navigation
- Coach-only Clients, Assignments, and Coach settings tabs
- Athlete app navigation is hidden while Coach Mode is active
- Client invitation records by email
- Pending invitation management
- Client roster foundation
- Assignment workspace placeholder
- Coach workspace state saved locally and through existing cloud sync
- Enter Coach Mode from Profile
- Exit back to the athlete app at any time

## Important scope
This sprint establishes the private coach workspace and synced invitation records. Actual cross-account email delivery, athlete acceptance, and secure coach-client database permissions require the next backend-enabled Coach Hub sprint.
