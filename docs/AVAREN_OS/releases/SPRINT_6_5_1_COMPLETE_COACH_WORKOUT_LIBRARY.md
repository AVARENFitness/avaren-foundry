# Sprint 6.5.1 — Complete Coach Workout Library

## Fixed
- Unassign is now visible for both assigned and started workouts.
- A workout can be cancelled after the athlete opens or starts it.
- Unassign remains available from the client profile and the main Assignments tab.

## Added
- 281 built-in common exercises.
- Exercise categories for chest, back, shoulders, arms, legs, glutes, calves, core, traps, forearms, lower back, cardio, and power movements.
- Equipment labels and searchable keywords.
- Existing program exercises and saved templates still merge into the same library.
- Custom exercise creation remains available for unique movements.

## Result
Coaches can build most individualized workouts without manually creating standard exercises.
