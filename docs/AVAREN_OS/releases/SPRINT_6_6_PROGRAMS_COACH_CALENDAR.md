# Sprint 6.6 — Programs & Coach Calendar

## Added
- Dedicated Coach Calendar tab
- Weekly calendar with all-client and single-client filters
- Drag-and-drop workout rescheduling
- Automatic reschedule notifications and phone push
- Duplicate previous week
- Schedule workouts, rest days, and deload days
- Multi-week program builder
- 4, 8, 12, and 16-week program durations
- Reusable weekly program structures
- Publish a full program to one client
- Athlete Home upcoming schedule with workouts, rest days, and deload days
- Existing active assignments backfilled into the calendar

## Architecture
Calendar workouts continue using the existing assignment engine, preserving notifications, push delivery, athlete launch, completion reports, and unassign behavior.
