# AVAREN Motion Library V1

The manifest at `public/motion/manifest.json` is the source of truth.

## Status values

- `in_production`: Artwork is planned or being created.
- `ready`: Every approved frame exists and may be shown.
- `incomplete`: Reserved for a published entry with a missing or broken frame.

## Folder structure

```text
public/motion/
├── manifest.json
├── neck-cars/
│   ├── frame-01.webp
│   ├── frame-02.webp
│   ├── frame-03.webp
│   ├── frame-04.webp
│   └── frame-05.webp
└── ...
```

Only mobility, stretching, Morning Mobility, Daily Reset, and Recovery Flow use these assets.
